# PEtest｜复旦大学体育考试题库检索

这是一个方便复旦同学在体育理论开卷考试时查题的网页。输入题干或关键词，模糊搜索内部数据库中的题目、已有选项、旧题库答案、补充提纲和教材。没有匹配内容时显示「无结果」。

题库来自 **[KevinWang15/fdty](https://github.com/KevinWang15/fdty)**。在原项目整理的资料基础上，我做了这个查询页面，希望让查题更方便一些。手机、电脑都能在线使用，也可以提前下载离线版。

感谢原作者和参与整理、补充资料的同学，让这些积累能够继续帮助更多人。

## 💡 为什么做这个网页

今年（2026 年）复旦大学体育理论考试改到了学习通，原来适用于旧考试网站的自动答题脚本已经无法直接使用。考虑到学习通对自动化脚本的监管相对严格，我选择把已有题库整理成一个独立的检索网页，方便大家在开卷考试时手动查找和核对题目。

虽然考试平台变了，前人整理的题库仍然有参考价值。希望通过这个网页，让这些资料继续发挥作用，也省去一些翻找的时间。

### 🌐 在线使用

1. 打开 **[查询网页](https://fdhzy.github.io/fudan-PETest/)**。
2. 在搜索框输入题干或关键词，查看匹配结果。
3. 点击题干或「查看详情」，查看完整题目、已有选项和来源。

默认开启「模糊搜索」，支持部分题干、关键词组合、表述差异和部分错字。完整匹配排在前面，随后补充最多 60 条相关结果；相似结果不一定是同一道题，可以结合原文核对。关闭「模糊搜索」后，只显示同时包含全部关键词的内容。

模糊搜索支持常见写法归一：`8段锦`、`8断锦`、`八断锦` 均按 `八段锦` 检索。多个关键词可以用空格、标点或“和／与／及”分隔，例如 `木兰拳 八段锦`、`木兰拳和8断锦`；两个关键词之间可以隔着其他文字，出现顺序不限，结果必须同时包含全部关键词。结果较多时，可以增加关键词缩小范围；没有匹配结果时，可以缩短题干或更换关键词。

可以把网址加入浏览器收藏夹，方便下次使用。如果手机应用内打不开，可以复制网址到系统浏览器。

### 💻 离线使用

1. 打开仓库中的 **[index.html](./index.html)**，点击文件右上方的 **Download raw file（下载原始文件）**。
2. 将文件保存为 `index.html`（文件后缀为 `.html`）。
3. 在电脑上双击文件，或右键选择「打开方式」，使用 Edge、Chrome 等浏览器打开。

也可以 **[下载完整 ZIP](https://github.com/FDhzy/fudan-PETest/archive/refs/heads/main.zip)**，解压后打开其中的 `index.html`。

题库、提纲和教材 OCR 文字已经包含在这个 HTML 文件里，下载后用浏览器打开就能使用。题库、提纲与教材检索可完全离线使用；离线版不会自动更新，有新版时可以重新下载。

### 🔎 仅检索内部数据库

搜索范围为本项目收录的旧题库、补充提纲和教材 OCR 文字。没有匹配内容时显示「无结果」，不再提供外部搜索跳转或联网补充答案。启用题型、收藏或原始选项筛选时，搜索结果也会受这些条件限制。

## 🔍 主要功能

- **关键词与模糊搜索**：检索题干、已有选项和提纲原文，支持相关程度排序，也可切换为严格关键词匹配。
- **提纲资料**：新增木兰拳和八段锦的 115 条资料，可在「提纲资料」中单独查看、收藏和复制出处。
- **完整题目查看**：点击题干或「查看详情」，查看题目、已有选项及出处。
- **题目筛选**：支持按题型筛选，或仅查看有原始选项的题目。
- **答案与收藏**：支持显示或隐藏答案、收藏题目及加载更多结果。

收藏保存在当前浏览器中，不跨设备或浏览器同步；在线版与离线版的收藏也不会自动同步。

- **教材资料**：新增《大学体育》650 页 OCR 文字，按章节与页码组织；可单独筛选，查看整页文字、收藏及复制出处。

## 📝 题库说明

目前收录 **6501 道复旦大学体育考试旧题库题目**，包括 5730 道判断题和 771 道单选题。其中，198 道单选题已恢复原始选项，另外 573 道暂时没有找到完整选项，会在页面中标注。

另收录《木兰拳理论提纲(1).docx》的 **115 条原文资料**，加上教材 OCR 资料后，合计 **7266 条题目与资料**。原文中的重复编号、用字及表述均保留，未作事实校订；每条结果显示文件名和原条目编号。[查看提纲原文](./data/mulan-outline.md) · [结构化数据](./data/mulan-outline.json)。

另收录用户上传的《大学体育》（马祖勤主编，2023 年 6 月第 1 版）PDF 中 **650 个有文字的正文页**，覆盖体育基础理论及各运动项目。每页保留章节、书页和 PDF 页码；PDF 第 14–664 页为提取范围，其中第 91 页无 OCR 文字。封面、前言、目录和版权页未纳入检索。

教材内容来自扫描件已有 OCR 层，仅清理部分识别换行，**未逐字校订**；图表、公式、跨页段落及识别错字请结合原 PDF 核对。页面不把教材内容标成标准答案。网页内嵌检索文字，原始 PDF 未放入仓库。[查看教材结构化数据](./data/university-pe-textbook.json)。导入脚本：`python scripts/import-textbook.py /path/to/source.pdf`（需要 PyMuPDF）。

补充资料使用本地全文与相关度检索，展示可核对的原文，不接入大模型生成答案，也不把资料条目当作判断题或单选题。

这份题库还没有和今年学习通的题目逐一核对，答案也沿用了旧题库内容。实际题目和选项顺序可能有变化，所以查询结果中的答案字母不一定对应当前题目的选项，需要结合具体内容判断。

旧题库数据快照：2026-11-19；教材资料更新：2026-11-25。网页提供手动查询功能，不包含学习通自动答题脚本。
